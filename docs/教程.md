## 1. 成品长什么样

| 模块 | 路由 | 说明 |
| --- | --- | --- |
| 首页 | `GET /` | 已发布文章分页列表，支持 `?keyword=` 搜索标题/标签、`?category=` 分类筛选、`?page=` 翻页 |
| 详情页 | `GET /article/{id}` | 正文、阅读量自增、标签、相关文章 |
| 后台列表 | `GET /admin` | 含草稿的全部文章、统计卡片、搜索、分页 |
| 新建 | `GET /admin/articles/new` + `POST /admin/articles` | 表单 + 校验 |
| 编辑 | `GET /admin/articles/{id}/edit` + `POST /admin/articles/{id}` | 同上 |
| 删除 | `POST /admin/articles/{id}/delete` | POST + 二次确认 |

**技术栈**：Spring Boot 3.2.5 / Spring MVC / Spring Data JPA(Hibernate 6) / Thymeleaf / Jakarta Bean Validation / H2 或 MySQL 8 / JUnit 5 + AssertJ。

**学完你能掌握**：分层架构、JPA 实体与生命周期回调、Thymeleaf 片段复用、表单绑定与校验、Specification 动态查询、分页、全局异常处理、Profile 切换数据库、用 curl 做接口验收、分阶段 Git 提交。

### 4.3 实体：字段怎么设计

```java
@Entity
@Table(name = "article")
public class Article {
    @Id @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 150)
    private String title;          // 标题

    @Column(length = 300)
    private String summary;        // 摘要，留空时由正文自动截取

    @Lob
    @Column(nullable = false)
    private String content;        // 正文（大文本）

    @Column(length = 50)  private String category;   // 分类
    @Column(length = 200) private String tags;       // 标签，逗号分隔
    @Column(length = 50)  private String author;

    @Column(nullable = false) private Integer views = 0;      // 阅读量
    @Column(nullable = false) private Boolean published = true; // false = 草稿

    @Column(nullable = false, updatable = false)
    private LocalDateTime createdAt;

    @Column(nullable = false)
    private LocalDateTime updatedAt;

    @PrePersist
    public void onCreate() {
        LocalDateTime now = LocalDateTime.now();
        this.createdAt = now;
        this.updatedAt = now;
        if (this.views == null) this.views = 0;
        if (this.published == null) this.published = true;
    }

    @PreUpdate
    public void onUpdate() { this.updatedAt = LocalDateTime.now(); }

    /** 摘要为空时用正文前 120 字兜底 */
    public String getDisplaySummary() {
        if (summary != null && !summary.isBlank()) return summary;
        String plain = content.replaceAll("\\s+", " ").trim();
        return plain.length() <= 120 ? plain : plain.substring(0, 120) + "…";
    }
    // getter / setter 省略
}
```

要点：

- **时间戳交给生命周期回调**（`@PrePersist`/`@PreUpdate`），而不是每个 Service 方法里手写 —— 以后任何入口写入数据都不会漏。
- `tags` 用逗号分隔的字符串而不是关联表 —— 个人博客量级够用，省一张表和一次联表查询。
- `published` 让后台能存草稿，前台只查已发布。

### 4.4 Repository：简单的用方法名，复杂的用 `@Query`

```java
public interface ArticleRepository extends JpaRepository<Article, Long>,
                                           JpaSpecificationExecutor<Article> {

    long countByPublishedTrue();
    long countByPublishedFalse();

    @Query("""
            select a.category, count(a)
            from Article a
            where a.published = true and a.category is not null and a.category <> ''
            group by a.category
            order by count(a) desc, a.category asc
            """)
    List<Object[]> countGroupByCategory();
}
```

### 4.5 Service：业务规则集中在这里

```java
@Service
public class ArticleService {
    private final ArticleRepository articleRepository;
    public ArticleService(ArticleRepository articleRepository) { ... }

    @Transactional
    public Article viewAndIncrease(Long id) {
        Article a = getById(id);
        a.setViews(a.getViews() == null ? 1 : a.getViews() + 1);
        return articleRepository.save(a);
    }

    @Transactional(readOnly = true)
    public Article getById(Long id) {
        return articleRepository.findById(id)
                .orElseThrow(() -> new ArticleNotFoundException(id));
    }
}
```

约定：**读操作加 `readOnly = true`**（Hibernate 会跳过脏检查，也能避免误写）；查不到就抛自定义异常，由全局异常处理器翻译成 404。

## 6. 第四步：后台管理（提交 2 下）

### 6.1 表单提交的完整链路

```java
@Controller
@RequestMapping("/admin")
public class AdminController {

    @PostMapping("/articles")
    public String create(@Valid @ModelAttribute("articleForm") ArticleForm form,
                         BindingResult bindingResult,
                         Model model,
                         RedirectAttributes redirectAttributes) {
        if (bindingResult.hasErrors()) {
            model.addAttribute("mode", "create");
            return "admin/form";            // 有错就留在表单页回显
        }
        Article saved = articleService.create(form);
        redirectAttributes.addFlashAttribute("message", "文章《" + saved.getTitle() + "》已保存");
        return "redirect:/admin";           // 成功后重定向，避免刷新重复提交
    }
}
```

三个关键点：

1. **`BindingResult` 必须紧跟带 `@Valid` 的参数**，否则校验异常会直接抛出。
2. **成功后 `redirect:` + `FlashAttribute`** —— 这是 Post/Redirect/Get 模式，刷新页面不会重复提交；Flash 属性只在一次重定向内有效，正好用来显示「保存成功」。
3. **删除用 POST 而不是 GET 链接** —— 避免浏览器预取或爬虫误删数据，前端再配一个 `onsubmit="return confirm(...)"`。

### 6.2 路由一览

| 方法 | 路由 | 行为 |
| --- | --- | --- |
| GET | `/admin` | 列表 + 统计 + 搜索 + 分页 |
| GET | `/admin/articles/new` | 新建表单 |
| POST | `/admin/articles` | 保存 |
| GET | `/admin/articles/{id}/edit` | 编辑表单 |
| POST | `/admin/articles/{id}` | 保存修改 |
| POST | `/admin/articles/{id}/delete` | 删除 |

> 本教程按需求**没有做登录校验**，`/admin` 任何人可访问。要上线请先加 Spring Security（见进阶路线）。

## 7. 第五步：完善——校验、分页搜索、异常处理（提交 3）

### 7.1 为什么用表单 DTO，而不是直接绑定实体

```java
public class ArticleForm {
    @NotBlank(message = "标题不能为空")
    @Size(max = 150, message = "标题不能超过 150 个字符")
    private String title;

    @NotBlank(message = "正文不能为空")
    private String content;

    @Size(max = 50, message = "分类不能超过 50 个字符")
    private String category;
    // ...

    private boolean published = true;      // 用原始类型，默认发布
}
```

两个原因：

1. **校验注解属于入参边界**，放 DTO 比放实体清晰；
2. **避开绑定陷阱**：如果直接绑定实体，而实体字段是 `private Boolean published = true;`，那么请求里**完全没带** `published` 参数时，Spring 不会覆盖这个初始值，文章会被当成「已发布」。用 DTO 的原始类型 + 单一处语义处理，就不会有歧义。

> 浏览器表单里 Thymeleaf 的 `th:field` 会额外渲染一个 `_published` 隐藏字段，所以「未勾选」能被正确绑定成 `false`；这一点在 `ArticleForm` 的类注释里也写清楚了。

### 7.2 动态查询：用 Specification，别堆方法名

「只看已发布 + 关键字 + 分类」三个条件两两组合，用方法名派生要写 8 个 `findByXxxAndYyyOr...`。改用 Specification：

```java
private Specification<Article> publishedSpec(String keyword, String category, boolean onlyPublished) {
    return (root, query, cb) -> {
        List<Predicate> predicates = new ArrayList<>();
        if (onlyPublished) {
            predicates.add(cb.isTrue(root.get("published")));
        }
        if (StringUtils.hasText(category)) {
            predicates.add(cb.equal(root.get("category"), category.trim()));
        }
        if (StringUtils.hasText(keyword)) {
            String like = "%" + keyword.trim().toLowerCase() + "%";
            // 只对标题与标签做不区分大小写的匹配。
            // 正文映射成 @Lob（CLOB），Hibernate 不允许对 CLOB 调用 lower()。
            predicates.add(cb.or(
                    cb.like(cb.lower(root.get("title")), like),
                    cb.like(cb.lower(root.get("tags")), like)
            ));
        }
        return cb.and(predicates.toArray(new Predicate[0]));
    };
}
```

配合分页与参数收敛：

```java
private Pageable pageable(int page, int size) {
    int safePage = Math.max(page, 1);
    int safeSize = Math.min(Math.max(size, 1), 50);   // 防止 size=100000 打穿
    return PageRequest.of(safePage - 1, safeSize, Sort.by(Sort.Direction.DESC, "createdAt", "id"));
}
```

### 7.4 全局异常处理

```java
@ControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(ArticleNotFoundException.class)
    @ResponseStatus(HttpStatus.NOT_FOUND)
    public String handleArticleNotFound(ArticleNotFoundException ex, Model model) {
        model.addAttribute("errorTitle", "文章走丢了");
        model.addAttribute("errorMessage", ex.getMessage());
        return "error/404";
    }

    @ExceptionHandler(Exception.class)
    @ResponseStatus(HttpStatus.INTERNAL_SERVER_ERROR)
    public String handleException(Exception ex, HttpServletRequest request, Model model) {
        log.error("处理请求 {} 时发生异常", request.getRequestURI(), ex);
        return "error/500";
    }
}
```

配套 `templates/error/404.html`、`error/500.html`，用户看到的是友好页面，堆栈只进日志。

```java
class ArticleServiceTest {
```

```yaml
    url: jdbc:mysql://localhost:3306/myblog?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false
    driver-class-name: com.mysql.cj.jdbc.Driver
    username: root
    password: 你的密码
  jpa:
    hibernate:
      ddl-auto: update
    database-platform: org.hibernate.dialect.MySQLDialect
  h2:
    console:
      enabled: false
```

### 8.3 启动

```powershell
java -jar target/my-blog-0.0.1-SNAPSHOT.jar --spring.profiles.active=mysql
```

`pom.xml` 里需要 MySQL 驱动：

```xml
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
```

也可以先手工执行 `db/schema-mysql.sql` 建表，再把 `ddl-auto` 改成 `none`（生产环境更稳妥）。

## 10. 第八步：Git 分阶段管理与推送

### 10.1 三次阶段提交（本项目实际历史）

```powershell
# 提交 1：骨架
git add -A && git commit -F commit1.txt     # chore: 初始化 Spring Boot 博客项目骨架

# 提交 2：核心功能
git add -A && git commit -F commit2.txt     # feat: 实现文章发布、列表、详情与后台管理

# 提交 3：完善
git add -A && git commit -F commit3.txt     # refactor: 完善校验、分页搜索、异常处理与 MySQL 支持
```

好处是回头看每一步在做什么一目了然；写中文提交信息建议用 `-F 文件` 的方式，避免命令行编码问题（FAQ 第 6 条）。

### 10.2 .gitignore 要点

```gitignore

.run-tmp/
*.log
.idea/
.vscode/
```

### 10.3 推送到 GitHub

```powershell
git remote add origin https://github.com/<你的用户名>/my-blog.git
git push -u origin main
```

用 GitHub CLI 更省事：

```powershell
gh auth login                     # 浏览器授权
gh repo create my-blog --public --source=. --push
```

**想让提交历史体现「分阶段推送」**，可以按提交逐个推：

```powershell
git push origin <提交1的sha>:refs/heads/main
git push origin <提交2的sha>:refs/heads/main
git push origin <提交3的sha>:refs/heads/main
```

国内网络连不上 `github.com` 时，先分清是哪一层的问题：`api.github.com` 正常但 `github.com` 超时，通常是 DNS 解析到了不可达 IP，可以临时用固定 IP 绕过：

```powershell
git -c http.curloptResolve=github.com:443:140.82.114.3 push
```

## 11. 常见问题速查（FAQ）

| # | 症状 | 原因 | 解决 |
| --- | --- | --- | --- |
| 1 | 启动即报 `Unable to create tempDir ... AccessDeniedException` | 内嵌 Tomcat 需要在 `java.io.tmpdir` 下建临时目录，而该目录不可写 | 启动时加 `-Djava.io.tmpdir=<可写目录>`，并把该目录加入 `.gitignore` |
| 2 | 搜索报 `Parameter 1 of function 'lower()' has type 'STRING', but argument is of type 'java.lang.String'` | 正文用 `@Lob` 映射成 CLOB，Hibernate 不允许对 CLOB 调用 `lower()` | 搜索范围收敛为标题与标签（或用 `cast`），并在注释里写明原因 |
| 3 | 打开新建文章页直接 500，日志 `Could not bind form errors using expression "all"` | `#fields.hasAnyErrors()` 写在了 `<form th:object>` **外面** | 把用到 `#fields` 的元素移进表单作用域内 |
| 4 | 没勾「立即发布」的文章却在前台可见 | 表单直接绑定实体，实体字段是 `Boolean published = true`，请求未带该参数时初始值生效 | 改用表单 DTO，`boolean` 原始类型 + 在一处统一处理发布语义 |
| 5 | `mvn test` 全部报 `Could not initialize plugin: MockMaker` | 运行环境（受限沙箱/权限受限）下 ByteBuddy agent 无法加载 | 在正常终端里跑；或指定可写的临时目录；这是环境问题不是代码问题 |
| 6 | 提交信息中文乱码 | 命令行参数编码差异 | `git commit -F 提交信息.txt`（文件用 UTF-8） |
| 7 | `github.com` 连不上，但 `api.github.com` 正常 | DNS 把 github.com 解析到了不可达 IP | `git -c http.curloptResolve=github.com:443:<可用IP> push` |
| 8 | 想重置数据 | H2 文件库持久化在 `data/` | 关掉应用，删除 `data/` 目录，重启会重新写入演示数据 |
| 9 | 控制台中文输出乱码 | Windows 控制台代码页与源文件编码不一致 | 源文件统一 UTF-8；必要时 `chcp 65001`，或给 gcc 加 `-fexec-charset=GBK` |
| 10 | 后台谁都能进 | 按需求未做登录 | 上线前加 Spring Security（见下节） |
| 11 | 页面改了没生效 | 模板缓存 | 开发期 `spring.thymeleaf.cache=false` |
| 12 | `ddl-auto: update` 会不会删数据 | update 只加不改不删 | 改字段类型/重命名时手动写迁移脚本，别指望它 |

## 12. 进阶路线与延伸资源

按性价比排序，每一批做完都是一个可提交的独立改动：

**第一批 · 阅读体验（1～2 天）**
- Markdown 渲染：[commonmark-java](https://github.com/commonmark/commonmark-java)（服务端渲染，记得转义 HTML）
- 编辑器：[Vditor](https://github.com/Vanessa219/vditor) 或 [EasyMDE](https://github.com/Ionaru/easy-markdown-editor)
- 代码高亮：[PrismJS](https://github.com/PrismJS/prism)；再加目录 TOC、阅读时长、暗色模式

**第二批 · 互动与分发**
- 评论：[giscus](https://github.com/giscus/giscus)（基于 GitHub Discussions，零后端）或 [Waline](https://github.com/walinejs/waline)
- RSS / sitemap / Open Graph meta
- 搜索：数据量小用 Fuse.js 前端搜索，大了上 Hibernate Search + Lucene

**第三批 · 后台与运维**
- 登录鉴权：Spring Security（表单登录 + 记住我）
- 图片上传与压缩：[Thumbnailator](https://github.com/coobird/thumbnailator)
- 容器化与 CI：[Jib](https://github.com/GoogleContainerTools/jib) 或 Dockerfile + Nginx，GitHub Actions 自动 `mvn test` + 构建镜像

**官方文档（第一手资料，强烈建议通读一遍）**
- [Spring Boot 官方文档](https://docs.spring.io/spring-boot/index.html)
- [Spring Data JPA 参考手册](https://docs.spring.io/spring-data/jpa/reference/index.html)
- [Thymeleaf 官方文档](https://www.thymeleaf.org/documentation.html)
- [Spring Guides 动手示例](https://spring.io/guides)

**可以读源码的开源项目**
- [halo-dev/halo](https://github.com/halo-dev/halo) —— Java 生态最成熟的博客/CMS，看插件化与后台设计
- [langhsu/mblog](https://github.com/langhsu/mblog) —— Spring Boot + JPA + Freemarker，技术栈最接近本项目
- [zhangyd-c/OneBlog](https://github.com/zhangyd-c/OneBlog) —— 功能划分清楚的 Spring Boot 博客

**学习建议**：每加一个功能就补一个测试、开一个分支、留一条清晰提交。这个项目本身就是在这样的节奏里长起来的——三次提交分别对应「骨架能跑」「功能闭环」「细节完善」，任何一步都是可运行状态。
